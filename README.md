# 1999 秘密客抽測工具

臺北市民當家熱線 1999 話務品質稽核用的測試工具。以臺北市政府常見問答（FAQ 8,323 則，由 faq-crawler 每日同步）為標準答案，
提供兩種測試：

- **智能出題**：一次出幾十到幾千題，拿去測智能客服，匯出 Excel 逐題比對答案
- **秘密客出題**：抽一則 FAQ，產生秘密客打 1999 用的對話腳本、追問清單與標準答案

網址：<https://andy939.github.io/1999-mystery-shopper/desktop.html>

## 檔案

- `desktop.html` — 桌機版（主要版本）
- `mobile.html` — 手機版：抽題 → 撥 1999 → 看著腳本問（可加到主畫面）。腳本跟桌機版一樣用 AI 題的問法與追問，🔴 過時題目不會用到
- `cstest.json` — 智能題庫 **10,140 題**（AI 出題 10,120 題＋人工標竿 20 題），涵蓋 4,613／8,331 則 FAQ。放在 `data/` 外面，爬蟲同步時不會被蓋掉
- `followups.json` — 多輪追問腳本：每則 FAQ 一句開場＋2 句追問，每句只問一件事、附 FAQ 原文正解（答案一定在該則 FAQ 內）。秘密客出題時，有腳本的 FAQ 改用這些追問。規則見 [tools/追問出題說明.md](tools/追問出題說明.md)，用 `python tools/merge_fu.py` 驗證合併
- `data/` — FAQ 題庫：`index.json` 為索引，`org-XX.json` 為各局處答覆（點到才載入）。由 faq-crawler 自動產生，請勿手動修改
- `1999秘密客腳本包.pdf` — 12 通離線腳本包（A5 大字）

## 桌機版功能

左側選單由上到下：

| 頁面 | 用途 |
|---|---|
| 🧪 智能出題 | 打開網頁時的預設頁，會自動出 20 題 L1。可選題數（最多 9,999）、局處（可打字搜尋）、難度 L0～L4、題型；可複製題目、匯出 Excel。點一題鎖定並看標準答案，再點一次回到清單 |
| 🔍 問答查詢 | 搬自爬蟲網站的問答查詢，直接讀爬蟲的 `faq.json`、`hits.json`（每天更新，含已下架、附件、更新日期、點閱數）。查法跟爬蟲網站「搜尋」一致：關鍵字＋BM25，字面符合的全部列出，不到 50 筆再補字詞相近的（分隔線下），口語整句也查得到；不搬語意查詢（e5-small，省得下載 113 MB 模型）。年份、排序（相關度／發布日期／點閱數／下版日期／標題）、只看有附件、含已下架、局處分類、匯出 Excel；點一題鎖定看全文、複製標題／答案；全文下方列出這則在智能題庫的題目，可按「🎯 用這則秘密客出題」直接產生腳本。點進來才下載資料 |
| 🎯 秘密客出題 | 從「全部局處」（依點閱列前 300 題）或單一局處挑題，點一題先看完整內容，按「📝 出題」才產生腳本；也可「🎲 本局」「🎲 隨機」抽題 |
| 💬 對話腳本 | 「客」＝秘密客台詞，「員」＝由標準答案組成的正解版 |
| ❓ 追問清單 | 依序追問，問過的打勾 |
| ✅ 標準答案 | 對照專員講了哪些、漏了哪些 |
| 📎 FAQ 來源 | 腳本每一句台詞的出處 |
| 🛠 資料維護 | 補題的參考依據：智能題庫各難度題數、涵蓋 FAQ、涵蓋率、暫停題數；「補題建議」依目前數字自動產生；「還沒有題目的 FAQ」依點閱數多→少排（點閱高＝民眾常問，優先出題） |

對話腳本到 FAQ 來源這四頁要先出題才能點。「複製本頁」「列印本頁」只輸出目前這一頁。

## 智能題庫的難度

| 難度 | 題數 | 說明 |
|---|---|---|
| L0 關鍵詞 | 1,509 | 只打重點關鍵詞（照官網原字、只用中文詞），測最基本的檢索 |
| L1 直述 | 4,830 | 接近 FAQ 標題的問法 |
| L2 口語／用詞落差 | 2,239 | 生活化講法，用詞跟 FAQ 標題差很遠 |
| L3 條件判斷 | 930 | 給年齡、身分、日期等條件，要套用 FAQ 的規定 |
| L4 錯誤前提／多意圖 | 1,346 | 民眾說錯要先更正，或一次問兩件事 |

合計 10,854 題，涵蓋 4,987／8,321 則 FAQ（60%），還有 3,334 則沒有題目；點閱前 3,000 名都有 L1（2026-10-26）。最新數字看網站「🛠 資料維護」。

有 AI 題的 FAQ，秘密客出題的開場與追問也會改用 AI 題的問法；沒有的才用規則模板。

## 補題與過時檢查

出題與過時檢查工具在 `tools/`，說明見 [tools/README.md](tools/README.md)。爬蟲每天同步 FAQ 後，GitHub Actions 會自動檢查題目有沒有因 FAQ 改版而過時，結果寫進 `stale.json`，網站上方會顯示過時題數，🔴 題目暫停出題；FAQ 下架、內容有變、L0 搜不到的題目會自動從題庫下架，記在 `tools/removed.json`。

補題時參考「🛠 資料維護」：先依點閱數順序替還沒有題目的 FAQ 出 L1，再補涵蓋率最低的難度。
