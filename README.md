# 1999 秘密客抽測工具

臺北市民當家熱線 1999 話務品質稽核用的測試工具。以臺北市政府常見問答（FAQ 8,323 則，由 faq-crawler 每日同步）為標準答案，
提供兩種測試：

- **智能出題**：一次出幾十到幾千題，拿去測智能客服，匯出 Excel 逐題比對答案
- **秘密客出題**：抽一則 FAQ，產生秘密客打 1999 用的對話腳本、追問清單與標準答案

網址：<https://andy939.github.io/1999-mystery-shopper/desktop.html>

## 檔案

- `desktop.html` — 桌機版（主要版本）
- `mobile.html` — 手機版：抽題 → 撥 1999 → 看著腳本問（可加到主畫面、離線可用；尚未改用 AI 題）
- `cstest.json` — 智能題庫 **6,078 題**（AI 出題 6,058 題＋人工標竿 20 題），涵蓋 2,036 則 FAQ。放在 `data/` 外面，爬蟲同步時不會被蓋掉
- `data/` — FAQ 題庫：`index.json` 為索引，`org-XX.json` 為各局處答覆（點到才載入）。由 faq-crawler 自動產生，請勿手動修改
- `1999秘密客腳本包.pdf` — 12 通離線腳本包（A5 大字）

## 桌機版功能

左側選單由上到下：

| 頁面 | 用途 |
|---|---|
| 🧪 智能出題 | 打開網頁時的預設頁，會自動出 20 題 L1。可選題數（最多 9,999）、局處（可打字搜尋）、難度 L0～L4、題型；可複製題目、匯出 Excel。點一題鎖定並看標準答案，再點一次回到清單 |
| 🎯 秘密客出題 | 從「全部局處」（依點閱列前 300 題）或單一局處挑題，點一題先看完整內容，按「📝 出題」才產生腳本；也可「🎲 本局」「🎲 隨機」抽題 |
| 💬 對話腳本 | 「客」＝秘密客台詞，「員」＝由標準答案組成的正解版 |
| ❓ 追問清單 | 依序追問，問過的打勾 |
| ✅ 標準答案 | 對照專員講了哪些、漏了哪些 |
| 📎 FAQ 來源 | 腳本每一句台詞的出處 |

後四頁要先出題才能點。「複製本頁」「列印本頁」只輸出目前這一頁。

## 智能題庫的難度

| 難度 | 題數 | 說明 |
|---|---|---|
| L0 關鍵詞 | 289 | 只打重點關鍵詞，測最基本的檢索 |
| L1 直述 | 1,875 | 接近 FAQ 標題的問法 |
| L2 口語／用詞落差 | 2,046 | 生活化講法，用詞跟 FAQ 標題差很遠 |
| L3 條件判斷 | 730 | 給年齡、身分、日期等條件，要套用 FAQ 的規定 |
| L4 錯誤前提／多意圖 | 1,138 | 民眾說錯要先更正，或一次問兩件事 |

有 AI 題的 FAQ，秘密客出題的開場與追問也會改用 AI 題的問法；沒有的才用規則模板。

## 補題

出題流程與工具在專案的 `出題工具/` 資料夾（不發布到網站）：`prep.py` 挑還沒有 AI 題的 FAQ → 依 `出題說明.md` 分批出題 → `merge.py --write` 驗證後合併進 `cstest.json`。

## 說明

答覆內容請以市府原始問答頁與各業管機關最新公告為準。

資料來源：臺北市政府常見問答，各局處發布，著作權屬各發布機關。
