# 1999 秘密客抽測工具

臺北市民當家熱線 1999 話務品質稽核用的秘密客腳本產生器。以市府常見問答（2026-09-04 匯出）為標準答案，
產生完整對話模擬、追問清單，以及每一句話的 FAQ 出處。

- `mobile.html` — 手機版：抽題 → 撥 1999 → 看著腳本問（可加到主畫面、離線可用）
- `desktop.html` — 桌機版：三欄式抽測台，可列印／存 PDF
- `1999秘密客腳本包.pdf` — 12 通離線腳本包（A5 大字）

## 說明

對話模擬中「客」為秘密客台詞，「員」為由該題常見問答原文組成的正解版，供比對話務人員實際說法的落差。
答覆內容請以市府原始問答頁與各業管機關最新公告為準。

資料來源：臺北市政府常見問答，各局處發布，著作權屬各發布機關。
